## 📱 Featured Project: Auto Analytics

[![Get it on Google Play](https://img.shields.io/badge/Google_Play-Get_it_on_Play_Store-414141?style=flat-square&logo=google-play)](https://play.google.com/store/apps/details?id=com.dariusepure.caractivitylog)
[![Download APK](https://img.shields.io/badge/Direct_Release-.apk_Download-0284c7?style=flat-square&logo=android)](https://github.com/dariusepure/auto_analytics/releases/latest/download/auto_analytics.apk)
[![Source Code](https://img.shields.io/badge/Repository-auto__analytics-24292e?style=flat-square&logo=github)](https://github.com/dariusepure/auto_analytics)

**Auto Analytics** is an all-in-one Android companion application designed to empower drivers with data-driven vehicle maintenance:
- 🧠 **AI Diagnostics:** Smart diagnostic assistance powered by Google Gemini.
- 📄 **Smart Scanning:** Document and service receipt tracking with OCR.
- 📊 **Interactive Analytics:** Bento-style history logs and interactive Vico mileage & fuel charts.
- 🏗️ **Modern Architecture:** Built 100% in Kotlin with Jetpack Compose, Ktor 3.0, and Clean Architecture.
